# Contextual Risk in Generative-AI Translation

This repository contains research materials associated with the following study:

**Yasushi Tsubota, “Managing Contextual Risk in Generative-AI Translation: A Pilot Stress-Test Study and Prompt-Based Review Workflow for Japanese-to-English Translation.”**

## Contents

### `translation_evaluation_table.xlsx`

This file contains the materials used in the pilot evaluation, including:

- diagnostic Japanese test items,
- outputs from DeepL,
- outputs from ChatGPT (Direct),
- outputs from ChatGPT using the Structured Workflow,
- reviewable intermediate logs from the Structured Workflow,
- item-level contextual adequacy scores, and
- score rationales.

The evaluation dataset consists of five main contrastive categories and one supplementary metalinguistic component, for a total of 110 source items.

## Evaluation

Outputs were evaluated using a three-point contextual adequacy scale:

- **3**: contextually appropriate
- **2**: partially appropriate or under-specified without critical distortion
- **1**: critical contextual error

Further details on the dataset construction, evaluation procedure, and reliability analysis are provided in the accompanying paper.
